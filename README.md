# Human Resources Dataset Analysis

**Project Idea 3 — Team 5**

## Project Idea

This project focuses on analyzing a Human Resources (HR) dataset to discover patterns and insights related to employees, job satisfaction, performance, and other HR indicators. The goal is to support organizational decision-making through data analysis, forecasting, and interactive visualizations.

The project uses SQL and Python for data preparation and analysis, along with Tableau to create an interactive dashboard presenting the main findings.

## KPIs

The following Key Performance Indicators (KPIs) can be investigated using the HR dataset, depending on data availability:

- **Employee Attrition Rate:** Percentage of employees who left the organization.
- **Job Satisfaction:** Distribution of employees across job satisfaction levels.
- **Employee Performance:** Analysis of employee performance ratings.
- **Average Years at Company:** Average employee tenure within the organization.
- **Departmental Employee Distribution:** Number of employees across different departments.
- **Work-Life Balance:** Distribution of employee work-life balance ratings.

These KPIs will help identify workforce patterns and support data-driven HR decisions. Actual values and findings will be reported after analysis.
